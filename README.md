# Getting Started

## Download & Install
1. Clone the repo
2. Change directory to the root of the project - `cd .\Ithilien`
3. Run `npm install`

## Running the Client & Server
Via the root dir `\Ithilien` you can use:

- `npm run dev:server`
- `npm run dev:client`

> The server/client folders have further scripts to run them directly from their `package.json` files.
